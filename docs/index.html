Audio Deck saves named profiles that each pin a default output and input device, then switches your system to a profile in one click, one command or one Stream Deck button. Profiles live in a local JSON file. No account, no cloud, no background service.

Configuration

Two views, one tray,
that's the whole app.

Create and edit profiles on the Configuration view. The actions live as icons in the header tray and swap with the active view: new, edit, delete, save and cancel. Name the profile, pick an output device and an input device from the live dropdowns, then save.

  • New, edit and delete from the header tray; unavailable actions wear a red ring.
  • Output and input chosen independently per profile.
  • Deletions are confirmed before anything is removed.
  • Switch over to Quick Switch and you are one click from any setup.
