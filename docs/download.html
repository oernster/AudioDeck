Windows

Windows 10 or 11, 64-bit

Download for Windows

Setup program (.exe)

Windows may show a SmartScreen warning when you run this: here's why.

Run the setup: it installs per-user, so no administrator rights are needed. Upgrading over a copy that is already open is handled for you: the setup offers to close it first. It reads what is already installed and shows one screen for what that means, then a progress screen while it works and a screen saying how it went.
