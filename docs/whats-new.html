Changelog

What's new

Recent releases have focused on making every switch honest and every profile safe: a failed save no longer loses your profiles, a switch reports what really happened and two switches at once take turns. Before that came a Guide behind the Help menu, a window drawn entirely in pictures, a setup program that shows one screen at a time and the move from Windows alone to Windows, macOS and Linux.

v2.4.0

A failed save no longer loses your profiles

  • Profiles are written somewhere safe first and only then put in place, so a save that fails part way (on a full disk, say) leaves them exactly as they were. The copy before each save is kept beside the file as profiles.json.bak
  • Setting a profile's output or input to (None) now removes the device instead of saying "Saved" and keeping it
  • A switch reports what really happened. On Windows it names the uses that kept the old device; after every switch Audio Deck reads the defaults back, so a change the system accepted but did not make is reported rather than shown as done
  • Turning on a device a profile was waiting for applies only that device, so it no longer undoes a switch you made since
  • Two switches at once, such as two Stream Deck keys pressed together, now take turns instead of leaving the output of one profile with the input of the other
  • On macOS a device that drops out at the moment of a switch is waited for and applied when it comes back
  • Plainer messages: an offline device will apply when it reconnects as the same device, "Could not read devices" replaces a misleading "not available" and the command line gives each reason its own heading
  • On Linux and macOS an unexpected file-locking error no longer stops the window opening

  • Every footer on this site links every page; the stylesheet link changes whenever the stylesheet does, so a browser never pairs a new page with old styles
  • The documents name the PipeWire tools the Linux backend falls back on

v2.0.0

Linux and macOS as well as Windows

  • Audio Deck runs on Linux and macOS with the same profiles, the same window, the same command line and the same Stream Deck workflow on all three; the interface was overhauled too
  • On Linux it works with PulseAudio or PipeWire, leaves out monitor sources and picks up device changes live. It ships as a Flatpak
  • On macOS it speaks to CoreAudio directly with no new dependency and identifies devices by a stable ID, so profiles survive reboots and unplugs. It ships as a signed, notarised DMG
  • Profiles live in each platform's proper per-user data folder; only one window runs per user on every platform
v1.5.0

An update check that respects you

  • A few seconds after launch and once a day while the window is open, Audio Deck asks GitHub whether a newer version has been published, then offers Download, Skip This Version or Later
  • Help > Check for Updates runs a real check and reports every outcome, including an honest failure when GitHub cannot be reached
  • The request carries no identifier and nothing about your profiles; a failed check on the automatic path says nothing
